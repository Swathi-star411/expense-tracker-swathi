# SpendWise - Expense Tracker

SpendWise is a responsive personal expense tracking web application built using HTML, CSS and JavaScript.

It helps users record income and expenses, monitor their balance, set a monthly budget and understand their spending patterns.

## Features

- Add income and expense transactions
- Edit transactions
- Delete transactions
- View total income
- View total expenses
- Calculate current balance
- Filter transactions by income or expense
- Filter transactions by category
- Search transactions
- Persistent data using browser Local Storage
- Monthly budget tracking
- Budget progress indicator
- Category-wise expense chart
- Financial spending insight
- Form validation
- Dark mode
- Responsive design for desktop and mobile devices

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser Local Storage
- Chart.js

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server, or open it directly in a web browser.

## Data Storage

The application uses browser Local Storage to store transaction data, monthly budget information and theme preferences.

Therefore, the data remains available after refreshing the page.
